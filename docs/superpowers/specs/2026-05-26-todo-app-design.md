# DoIt — 个人待办清单 PWA

## 概述

DoIt 是一个纯前端个人待办清单 PWA（渐进式 Web 应用），采用看板风格管理任务，支持分类筛选、优先级标记和截止日期。数据存储在浏览器 LocalStorage，支持 JSON 导出/导入备份。

## 技术方案

- **技术栈**: 原生 HTML + CSS + JavaScript（无框架、无构建工具）
- **存储**: LocalStorage
- **PWA**: manifest.json + Service Worker 实现离线可用和桌面安装
- **托管**: GitHub Pages 或 Vercel 免费托管（一个 HTML 文件 + 静态资源）
- **适用范围**: 个人单设备使用

## 界面布局

采用看板三列布局 + 顶部筛选栏：

```
┌─────────────────────────────────────────────────┐
│  ✅ DoIt · 个人待办              📤导出  📥导入  │
├─────────────────────────────────────────────────┤
│  [全部]  [💼 工作]  [🏠 生活]  [📚 学习]       │
├──────────┬──────────┬───────────────────────────┤
│ 📋 待办   │ 🔄 进行中 │ ✅ 已完成                 │
│          │          │                           │
│ [任务卡片] │ [任务卡片] │ [已完成卡片·半透明]      │
│ [任务卡片] │          │                           │
```

### 任务卡片

每条任务显示为卡片，左边框颜色条表示优先级：
- 🔴 红色边框 = 高优先级
- 🟡 橙色边框 = 中优先级
- 🟢 绿色边框 = 低优先级

卡片内显示：标题、分类图标、截止日期、优先级标签。

## 数据模型

### Task

```json
{
  "id": "task_1706000000_abc123",
  "title": "买牛奶",
  "category": "生活",
  "priority": "high",
  "dueDate": "2026-05-26",
  "status": "todo",
  "createdAt": "2026-05-26T10:00:00Z",
  "updatedAt": "2026-05-26T10:00:00Z"
}
```

- `category`: "工作" | "生活" | "学习"
- `priority`: "high" | "medium" | "low"
- `status`: "todo" | "doing" | "done"

## 功能清单

### 核心功能
- **添加任务**: 弹窗输入标题、分类、优先级、截止日期
- **编辑任务**: 点击卡片编辑内容
- **删除任务**: 卡片上提供删除操作
- **拖拽切换状态**: 在待办/进行中/已完成三列之间拖拽卡片
- **分类筛选**: 顶部标签点击筛选，选"全部"显示所有
- **数据持久化**: LocalStorage 自动保存
- **导出/导入 JSON**: 备份和恢复数据

### PWA 功能
- manifest.json 定义应用名、图标、主题色
- Service Worker 缓存静态资源，支持离线访问
- 可添加到桌面/手机主屏幕，类原生体验

## 用户交互流程

1. 用户打开页面，看到看板三列，默认显示"全部"分类
2. 点击「+」按钮或列底部 → 弹出新建任务弹窗
3. 填写标题，选择分类/优先级/日期 → 点击添加 → 卡片出现在"待办"列
4. 拖拽卡片到"进行中"或"已完成"列 → 状态自动更新
5. 点击顶部分类标签 → 看板只显示该分类任务
6. 点击已有卡片 → 可编辑或删除
7. 点击导出 → 下载 JSON 文件；点击导入 → 选择 JSON 文件恢复数据
